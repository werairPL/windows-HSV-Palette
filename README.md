# windows-HSV-Palette
适用于windows系统的便携版HSV调色盘

支持亮暗主题切换与记忆  
窗口大小可调整，支持记忆  
可切换前景色与后景色  
支持色板颜色存储  
支持HEX快捷复制  

注意：不支持屏幕取色

只负责调试，有bug那就是大肥鱼的锅

v1.6.19使用Electron框架，动画更流畅，但包体尺寸更大（347MB）  
v1.7.6更换为Tauri框架，包体仅3.48MB，动画略有卡顿，两个版本酌情选择  
v1.8.1为1.7.6的稳定性修复版本，整体实用性已经超越1.6.19，建议选择1.8.1版本  

src后缀的zip文件为源代码
